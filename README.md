# Westbridge International University Website

A responsive, multi-page university website developed using **HTML5 and CSS3** as part of my web development learning journey.

The project focuses on semantic HTML structure, external CSS styling, responsive layouts, accessible navigation, and a professional university website design.

#Project Overview
Westbridge International University is a conceptual university website created for educational and web development practice. The design combines a deep forest green and champagne gold color palette with editorial layouts and a clean academic visual identity.

The website includes multiple pages covering admissions, academics, research, campus life, university news, and institutional information.

**Note:** This is a learning project, not an official university website. Institutional information and sample content are placeholders where verified details were unavailable.

#Technologies Used
- **HTML5** — Semantic page structure and content
- **CSS3** — Styling, layouts, navigation, and responsive design
- **CSS Grid and Flexbox** — Page layout and component alignment
- **Media Queries** — Responsive layouts for different screen sizes
- **Google Fonts** — Merriweather and Open Sans typography

#Features
- Multi-page university website
- Semantic HTML5 structure
- External CSS stylesheets
- Responsive desktop, tablet, and mobile layouts
- CSS-based dropdown navigation
- Keyboard focus indicators and skip navigation link
- Consistent typography, colors, and spacing
- University admissions and academic program sections
- Research and campus life sections
- Student Portal, Faculty Portal, and Library pages
- Inquiry form interface with native HTML validation
- Search interface prototype
- Reduced-motion accessibility support
- Organized project folder structure

#Website Pages
The website includes the following main sections:
- **Home** — University introduction and featured content
- **Admission** — Requirements, application process, scholarships, and international admissions
- **Academics** — Undergraduate programs, graduate programs, faculties, and academic resources
- **Research** — Research centers, projects, publications, and innovation
- **Campus Life** — Student organizations, activities, accommodation, and support services
- **News & Events** — University news, events, seminars, and announcements
- **About Us** — Institutional overview, mission, vision, leadership, and facilities
- **Contact** — Contact information, campus location, department contacts, and inquiry form

Additional pages include the Student Portal, Faculty Portal, Library, Search, Privacy Policy, and Accessibility.

#How to Run Locally
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your web browser.
4. Alternatively, use the Live Server extension in Visual Studio Code for local development.
5. Navigate through the website using the main navigation menu.

No package installation or build process is required.

#Limitations
- JavaScript and frontend frameworks are not used.
- Search functionality is a static interface without a search backend.
- Portal pages do not provide real authentication.
- The inquiry form does not submit or store user information.
- News and announcements are static rather than dynamically updated.
- Some images and fonts require an internet connection.
- Institutional details and sample content require verification before any real-world publication.

#Future Improvements
